# Lucent

lucent — AI-powered, browser-based background removal tool.

## Features
- 100% browser-based processing using WebAssembly and ONNX Runtime
- Privacy-first execution with no server uploads
- Unlimited high-resolution downloads without subscriptions
- Interactive before and after comparison slider
- Clipboard support for direct image pasting
- Customizable background colors, images, and gradients

## Tech Stack
- TypeScript
- React
- Tailwind CSS
- Vite
- WebAssembly

## Installation
```bash
git clone https://github.com/xreactivee/lucent.git
cd lucent
npm install
```

## Usage
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.
