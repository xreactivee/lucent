# Lucent

lucent — AI-powered background removal tool that processes images locally in the browser using WebAssembly and ONNX Runtime.

## Features
- 100% browser-based processing using WebAssembly and ONNX Runtime
- Privacy-first execution with local file handling and zero server uploads
- High-resolution image downloads without subscriptions or credit limits
- Interactive before and after comparison slider for previewing results
- Direct clipboard image pasting support for quick workflow integration
- Customizable background colors, gradients, and custom image uploads

## Tech Stack
- TypeScript
- React
- Tailwind CSS
- Vite
- WebAssembly

## Installation
```bash
git clone https://github.com/xreactivee/lucent.git
cd lucent
npm install
```

## Usage
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.
